# 💰 Expense Analyzer

A beginner-friendly Python data analysis project that uses **Pandas** to analyze personal expenses.

## 📌 Features

This project can:

- Read expense data from a CSV file
- Display the first few rows of the dataset
- Display information about the dataset
- Calculate total expenses
- Calculate expenses by category
- Find the category with the highest spending
- Filter expenses greater than Rs 1000
- Count the number of expenses greater than Rs 1000

## 🛠️ Technologies Used

- Python
- Pandas
